# 🚀 استمارة ونظام نادي البرمجة والذكاء الاصطناعي (Coding AI Club)

تطبيق ويب متكامل ومستجيب بالكامل (Single Page Application - SPA) مصمم بنمط **نماذج جوجل الأصلية (Google Forms UI)** باللغة العربية (RTL) مع **قاعدة بيانات دائمة لا تختفي**.

---

## 💾 حل مشكلة اختفاء البيانات (التخزين الدائم)

لضمان عدم ضياع بيانات المسجلين أبداً عند إغلاق المتصفح أو إعادة تشغيل الحاسوب:

### 1. قاعدة بيانات SQLite دائمة على القرص (`server.py` / `start.bat`)
* عند تشغيل الموقع عبر **`start.bat`** (أو `python server.py`)، يتم حفظ كل تسجيل تلقائياً في ملف قاعدة بيانات حقيقي على القرص باسم:
  **`coding_ai_database.db`**
* هذا الملف يبقى محفوظاً بشكل دائم على حاسوبك ولا يتأثر بإعادة التشغيل أو مسح كاش المتصفح.

### 2. مزامنة ثنائية الاتجاه مع Google Sheets (`google-apps-script.js`)
* في حال رفع الموقع على الإنترنت (استضافة مجانية مثل GitHub Pages أو Netlify)، يمكنك ربطه بجدول Google Sheets.
* يدعم النظام الآن **الحفظ والسحب (Two-Way Sync)** من Google Sheet دون تكرار السجلات.
* ضع رابط Web App في لوحة الإدارة (**Google Sheet**) أو داخل المتغير `DEFAULT_GOOGLE_SHEET_URL` في `index.html` لكي يعمل لجميع الطلبة من أي هاتف أو حاسوب.

### 3. تخزين المتصفح المتقدم + نسخ احتياطي JSON
* حفظ تلقائي في **IndexedDB** + **LocalStorage** كطبقة حماية إضافية.
* أزرار **نسخ احتياطي (JSON)** و **استعادة** داخل لوحة الإدارة لحفظ واسترجاع كامل قاعدة البيانات بضغطة زر.

---

## ▶️ طريقة التشغيل الدائمة محلياً
1. انقر نقراً مزدوجاً على الملف **`start.bat`** (أو شغّل `python server.py`).
2. سيفتح الموقع تلقائياً على: `http://localhost:3000`.
3. تأكد داخل **لوحة الأدمن** من ظهور شارة: `● متصل بقاعدة بيانات SQLite دائمة`.
